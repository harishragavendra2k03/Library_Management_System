# 📚 Library Management System

A simple **console-based Library Management System** developed using **Core Java**.

This project was created as part of the **SoftGrowTech Java Programming Internship** to demonstrate fundamental Java programming and Object-Oriented Programming concepts.

---

## 🎯 Project Objective

The main objective of this project is to create a simple system that allows users to manage books in a library.

The application provides functionality to:

- Add books
- Display all books
- Search books by ID
- Search books by title
- Delete books
- Issue books
- Return books

The project focuses mainly on **Core Java and OOP concepts** without using any database or external framework.
